Ketchup combines the stability of a modern Linux base with the flexibility of Arch. Minimal by default, customizable by design — starts from the CachyOS Live ISO profile and rebuilds the boot path, branding, installer, and a chunk of the default tool set on top of it.

Features

Everything tuned, nothing bloated

01

Limine, everywhere

A single bootloader across BIOS, UEFI and hybrid USB, with hash-pinned kernel/initramfs and automatic GRUB fallback when a disk's /boot can't be read by Limine.

Learn more →
02

Rust-first userland

alacritty, eza, bat, fd, ripgrep, sd, dust, procs, bottom, zoxide, starship, yazi, helix, zellij and more ship by default, alongside KDE Plasma and linux-zen.

Explore tools →
03

Ketchup Lens

Trace a real running program, or step through a toy CPU/MMU/cache/RAM/disk one instruction at a time — a teaching tool built into the OS itself.

Try it now →
04

Tuned, not just themed

zram with zstd, BBR, ananicy-cpp, scx_lavd, systemd-oomd and weekly fstrim are on by default; the live initramfs itself uses zstd so the boot-to-splash gap stays short.

See the tuning →
05

Built-in self-checks

ketchup-audit, ketchup-doctor and ketchup-irqfix turn "something feels off" into a concrete diagnosis instead of a forum post.

Run a check →
06

Offline-capable installer

Calamares installs straight from the live image — no network required — onto btrfs + zstd + subvolumes by default.

See install docs →
